# Internal State Machine & Trigger Logic
The `HybridDetector` must manage its compute budget internally using a State Machine:
1. STATE_YOLO (Default): Run the frame through YOLOv11.
2. STATE_FALLBACK: Suppress the YOLO output and immediately run RT-DETR on the SAME frame. This transition occurs ONLY IF:
   - Condition A (Semantic Uncertainty): YOLO detects an object, but its highest confidence score drops below a predefined threshold (e.g., `uncertainty_thresh = 0.55`).
   - Condition B (Spatial Uncertainty): YOLO returns 0 detections, AND the `is_track_lost` flag is `True` (indicating the object is likely still in the scene but missed by YOLO due to UAV dynamics/occlusion).
3. STATE_COOLDOWN: Once RT-DETR executes and returns detections, the system enters a strict cooldown period (e.g., `cooldown_frames = 10`). During this period, the detector forces STATE_YOLO and ignores fallback conditions to prevent model-switching oscillation. The counter decrements per frame.
